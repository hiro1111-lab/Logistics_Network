# 🚚 物流ネットワーク障害シミュレーター (Logistics Network Failure Simulator)

グラフ理論を活用し、物流・交通・通信ネットワークにおける脆弱性の特定と、障害発生時の影響範囲をリアルタイムにシミュレーション・可視化するWebアプリケーションです。

単なる最短経路探索にとどまらず、「どのルートが止まると循環配送が崩壊するか（強橋）」や、「上流の停止が下流にどう連鎖するか（カスケード故障）」といった現実の複雑な制約を数理モデルに落とし込み、定量的に評価します。

## ✨ 主な機能 (Features)

* **🔴 強橋（単一障害点）の自動検出**
  * ルートが1本遮断されるだけでネットワークの強連結性（循環）が失われる致命的な辺を特定します（計算量: $O(E \times (V+E))$）。
* **🛑 障害波及シミュレーション（カスケード故障の検出）**
  * 指定した拠点やルートが停止した際の「直接的な孤立」に加え、祖先ノードの到達可能性を追跡し、補給途絶によって連鎖的に発生する「カスケード故障」を正確に捕捉します。
* **🔄 迂回コストの定量分析**
  * 障害発生前後の最短経路を比較し、代替ルートへの迂回によって生じるコスト（距離・時間）の増大を自動計算します。
* **📊 ハイブリッド可視化システム**
  * ネットワーク規模に応じ、俯瞰に適した静止画（Matplotlib / ~80ノード）と、詳細な確認に適したインタラクティブ描画（PyVis / ~200ノード）を自動で切り替えます。

## 📁 モジュール構成 (Architecture)

保守性と拡張性を高めるため、役割ごとにファイルをモジュール分割しています。

* **`main.py`**
  * Streamlitを用いたアプリケーションの司令塔。ユーザーインターフェースの構築と各モジュールの統合制御を行います。
* **`algorithms.py`**
  * グラフ計算のコアロジック。強橋検出、カスケード故障探索、最短経路探索（迂回コスト計算）、安定したSCC（強連結成分）マップの生成など、計算処理を独立して担います。
* **`visualization.py`**
  * ネットワークの可視化ロジック。ノードの状態（正常、孤立、カスケード故障）やルートの属性（通常、強橋、遮断）に応じた動的なスタイリングと描画を行います。
* **`scenarios.py`**
  * 検証用のデモデータセット（関東17拠点の主要物流ネットワークシナリオなど）と、CSVファイルからのグラフ生成ロジックを管理します。

## 🚀 使い方 (Usage)

本システムは [Streamlit](https://streamlit.io/) を使用して構築されています。以下のコマンドでローカルサーバーを起動し、ブラウザ上で操作できます。

```bash
# 必要なライブラリのインストール
pip install networkx pandas matplotlib pyvis streamlit japanize-matplotlib

# アプリケーションの起動
streamlit run main.py
